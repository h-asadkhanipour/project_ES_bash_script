In this project, several goals will achieved:
- Provide a full instruction to setup and install all required packages and programs for ES pipeline, For someone who is a new linux OS user --> ES_pipeline_linux_configuration.md	
- Provide a yml file for conda configuration for gatk. --> ES_pipeline_env_configuration.yml
- Provide a bash script to run Exome Sequencing from raw fastq file to vcf. --> ES_SNP.sh
- Provide separate bash scripts to do CNV analysis and structural variant analysis. --> ES_CNV.sh ES_SV.sh (still developing)
- Provide a bash script to download annovar data. --> annovar_data_download_script.sh
- Provide a R script for modifying annotated vcf. ( runs as part of ES_filtering.sh ) --> vcf_modification_R_script.R
- Provide a bash script to automate vcf modification and filtering
